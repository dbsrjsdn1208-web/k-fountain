# K-파운틴

[wixette/fountain2html](https://github.com/wixette/fountain2html)의 실제 파서·HTML 출력·다섯 테마와 검정/파랑 화면 구조를 사용한 Fountain 편집기입니다. 원본 리비전은 `f7a741d06a3de6602efe04f4673daa315e3bc9da`이며, 수정하지 않은 원본과 테스트는 `vendor/fountain2html/`, 실제 사용하는 수정본은 `src/engine/`에 있습니다. Apache-2.0 출처와 라이선스를 보존했습니다.

## 쓰기와 미리보기

일반 텍스트 입력창에 Fountain 문법을 그대로 씁니다. `.장소`와 `INT. / EXT.`는 장면, `#`는 섹션입니다. `S#1`이나 `1.`을 장면으로 바꾸는 한국형 인식은 제거했습니다.

- Ctrl+B / I / U: `**굵게**`, `*기울임*`, `_밑줄_` 기호를 삽입하거나 해제합니다. 선택하지 않았으면 기호 사이에 커서를 놓습니다. 강조 조합과 실행 취소를 지원합니다.
- 구글 독스 붙여넣기: 복사한 일반 텍스트의 줄바꿈을 기준으로 유지하고 HTML의 굵게·기울임·밑줄만 기호로 바꿉니다. HTML과 텍스트 내용이 다르면 일반 텍스트를 보존합니다.
- 미리보기: 원본의 문단과 줄바꿈 처리를 따릅니다. 고정 대기 시간 없이 다음 화면 갱신에 반영하며 작성 위치를 따라갑니다. 한글 조합 중에는 입력 원문을 자동 수정하지 않습니다.
- 글꼴: 설정에서 이름을 직접 입력합니다. 기기에 설치되지 않은 글꼴은 Noto Serif KR로 대체됩니다.
- 등록 인물: 이름 전체, `(민서)`, 괄호를 포함한 등록 이름 `(인물)`, 뒤의 `(전화)`, 동시 대사 `^`를 지원합니다. 이름 줄을 마친 뒤 `@`를 추가하며 대사 중 지시문은 바꾸지 않습니다.
- 설정은 즉시 적용되고 자동으로 기억됩니다. 별도 설정 저장 버튼은 없습니다.

## 장면 번호

설정의 ‘장면 번호 자동’에서 선택합니다.

- **출력만 갱신**(기본): 원고의 번호는 건드리지 않고 미리보기와 PDF·DOCX에 순서대로 표시합니다.
- **원고에도 반영**: 표준 `.장소 #1#` 형식으로 추가·삭제·이동 순서에 맞게 원고 번호도 갱신합니다.
- **끄기**: 직접 입력한 장면 번호를 보존하고 출력합니다. 이미 원고에 쓴 번호를 삭제하지 않습니다.

TXT 내보내기는 별도로 `S#1.`, `S#1`, `1.`, `1` 표시를 선택합니다.

## 파일과 설치

- **저장 / Ctrl+S**: 처음에 `.fountain` 파일의 위치를 선택하고 이후에는 같은 파일을 갱신합니다.
- **다른 이름으로 저장 / Ctrl+Shift+S**: 새 이름과 위치를 선택합니다. 취소하거나 실패하면 기존 파일 연결은 유지됩니다.
- 파일 직접 저장은 지원되는 Chrome·Edge에서 사용할 수 있습니다. 그 외 브라우저는 다운로드 방식이며 같은 파일 덮어쓰기를 보장하지 않습니다. 재실행 시 브라우저가 파일 접근 권한을 다시 요청할 수 있습니다.
- **PDF / 인쇄**: 미리보기 인쇄 창에서 PDF 저장을 선택합니다. 브라우저 머리글·바닥글은 끄는 것을 권장합니다.
- **DOCX**: 편집 가능한 대본입니다. 구글 독스에서 열 수 있으나 글꼴과 페이지 배치는 해당 앱에 따라 달라질 수 있습니다.
- **TXT**: 기호를 제거한 읽기용 대본입니다. 원본 Fountain 파일 연결은 바뀌지 않습니다.
- **웹 앱 설치**: Chrome·Edge에서 사이트를 열고 앱 설치 버튼 또는 브라우저 설치 메뉴를 사용합니다. 첫 로딩과 캐시 준비가 끝나면 오프라인에서 편집·미리보기·파일 내보내기가 가능합니다. 업데이트는 열린 원고를 강제 새로고침하지 않습니다.
- **단일 파일**: `K-파운틴.html`은 설치 없이 열 수 있는 별도 파일입니다. 웹 앱 설치는 HTTPS 배포 주소에서 사용하세요.

원고는 서버로 전송하지 않습니다. 브라우저에 저장하는 임시 복구본은 실제 원고 파일과 구분해 표시합니다. 기기를 옮길 때는 `.fountain` 파일을 사용하세요. 글꼴·등록 인물은 해당 브라우저에 저장됩니다.

## 이전 원고

기존 브라우저 원고와 구버전 JSON 백업을 읽어 Fountain 텍스트로 이전합니다. 예전 강조는 기호로 바꾸고 당시 켰던 한국형 장면 기호는 표준 장면 문법으로 변환합니다. 기존 브라우저 저장 항목은 복구용으로 그대로 남깁니다. JSON 백업 내보내기는 제거했지만 열기/파일 드롭으로 기존 백업을 가져올 수 있습니다.

## 개발과 검증

미리보기의 글자를 클릭하면 해당 원고 위치로 이동합니다. 반복 문장을 검색하지 않고 파서가 보존한 글자별 원고 위치를 사용하며, 강조 기호·숨김 메모·자동 장면 번호도 반영합니다. 여백 클릭과 드래그 선택은 이동시키지 않습니다. 클릭 후 미리보기 위치는 유지되고 다음 키보드 입력부터 따라가기가 재개됩니다. 클릭만으로 원고나 실행 취소 이력이 바뀌지 않습니다.

Node.js 22 이상에서 `npm ci`, `npm run build`, `npm test`, `npm start` 순서로 실행합니다. 기본 로컬 주소는 `http://127.0.0.1:4173`입니다. `node scripts/build.mjs --standalone`은 단일 HTML도 생성합니다. 일반 웹 빌드는 DOCX 라이브러리를 별도 파일로 나눠 편집기 시작 시 실행하지 않습니다.

원본 테스트, 공식 문법 항목별 자체 회귀 검사, 붙여넣기·단축키·IME·장면 번호·저장 실패 및 취소·구버전 이전·오프라인 캐시 검사를 포함합니다. 공식 Fountain 인증은 아닙니다. 파일 선택·권한·덮어쓰기 흐름은 자동 검사에서 파일 API 대역을 사용하며, 운영체제의 실제 저장 창과 앱 설치는 지원 브라우저에서 별도 확인이 필요합니다.

라이선스와 수정 기록: `vendor/fountain2html/UPSTREAM.md`, `dist/THIRD-PARTY-NOTICES.txt`.
